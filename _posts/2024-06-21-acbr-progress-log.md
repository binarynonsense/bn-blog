<p>Changelog:</p>
<ul><li>Updated some of the core libraries to newer versions.
</li><li>Added mouse click+drag as an input option to scroll a page.
</li><li>Added touch screen input support: drag to scroll a page, pinch-zoom  to zoom in and out and double tap to switch between the default zoom  levels.
</li><li>Added Arabic localization (contributed by <a href="https://github.com/ahmed-0011" referrerpolicy="origin" rel="nofollow noopener">Ahmed (ahmed-0011)</a>).
</li><li>Made the UI rearrange its components if a right-to-left language is set.
</li><li>Added a Home Screen shown when there&#x27;s no file opened, with a button  to open a file dialog and lists of favorite files and folders and  latest files.
</li><li>Added Gamepad button mapping to the preferences.
</li><li>Added preferences, history and a convert files buttons to the Home Screen.
</li><li>Clicking the mouse wheel button now opens the quick menu (it can be configured in the preferences).
</li><li>Added the option to include folders in the input list of the convert  and create comics tools. The folders in the input list will be searched  for valid files to use during the conversion/creation process (there&#x27;s  an advanced option to enable searching them recursively and another to  select which file types are valid).
</li><li>Added an option in the convert comics tool to select between  choosing an output folder for all files or saving each one in the same  folder as its corresponding input file.
</li><li>Added an advanced option in the convert comics tool to select  between overwriting the output file if it already exists, save it with a  name not already in use or skip saving it.
</li><li>Added an experimental color mode preference (light or dark) for EPUB ebooks.
</li><li>Added an option in the preferences to set maximum number of latest files shown in the Home Screen.
</li><li>Added a new tool, Internet Radio, to search through the list of  radio stations available on radio-browser.info and open them in the  system&#x27;s browser or in ACBR&#x27;s audio player.
</li><li>Handled trying to open a file by launching a second instance (or  from the file explorer when the app is already running). The second  instance is canceled, as before, but the already running one now asks  for confirmation to open the provided file.
</li><li>Customized the ACBR Light theme so the Home Screen colors fit better with the rest of the design.
</li><li>Fixed left and right arrows not working on input fields inside modals.
</li><li>Fixed mouse drag being detected as click in the reader.
</li><li>Fixed some minor issues.
</li></ul>
<p>NOTE: This update changes the way the key mapping is stored so, if you had customized it, you may need to configure it again.
</p>
