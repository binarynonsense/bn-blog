<p>Changelog:</p>
<ul>
<li>Refactored the Reader's code for easier maintenance and future improvements. This should have no effect in how it works compared to the previous version.</li>
<li>Removed the old alternative PDF rendering lib, pdfjs, as keeping it was adding unneeded complexity to the code and increasing the program's size.</li>
<li>Fixed the default filter preview image used in the Preferences showing as broken due to a path change in a recent update.</li>
<li>Fixed the context menu showing the rotation entry in the Reader even in page modes that don't allow it.</li>
</ul>
