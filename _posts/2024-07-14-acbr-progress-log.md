<p>Changelog:</p>
<ul><li>Added EPUB metadata support to the file properties window.
</li><li>Added an EPUB metadata editor.
</li><li>Added a PDF metadata editor.
</li><li>Added an option in the history tool to set the maximum number of recent files to remember.
</li><li>Added a new tool to search and open comic books and audio files from the website &quot;Comic Book Plus&quot;.
</li><li>Changed the way numerical image file names are generated (used  during PDF extraction and in the comic creation tool) to pad them with  zeros, so viewers that don&#x27;t use natural sorting display the pages in  the correct order.
</li><li>Updated some of the core libraries to newer versions.
</li><li>Fixed modal windows letting Space and Enter key events be passed to their parent element.
</li><li>Fixed moving the toolbar slider sometimes made the page scroll.
</li><li>Fixed some minor issues.
</li></ul>
